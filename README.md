# The Salon Dollar

A free profit tool for salon owners. Three tabs:

1. **Start here** — what a percentage is and how to work yours out
2. **The Salon Dollar** — every target and what it is divided by
3. **Run your numbers** — a live calculator

## How it works

One file: `index.html`. No build step, no server, no database, no dependencies.
Everything runs in the visitor's browser and nothing is stored or sent anywhere.

To change it, edit `index.html` and push. GitHub Pages redeploys on its own.

Deep links: `#basics`, `#dollar`, `#calc`.
